# Replication guide

Run commands from the repository root with Python 3.10+.

## Required validation

```bash
python3 -m pytest -q
make smoke
python3 -m telemetry_contracts.cli benchmark --config benchmarks/builtin.json --format markdown
```

## Benchmark metrics and current impact reports

```bash
python3 -m telemetry_contracts.cli benchmark --config benchmarks/builtin.json --format json --output reports/current_impact.json
python3 -m telemetry_contracts.cli benchmark --config benchmarks/builtin.json --format markdown --output reports/current_impact.md
python3 -m telemetry_contracts.cli taxonomy --findings reports/current_impact.json --format json --output reports/current_impact_taxonomy.json
python3 -m telemetry_contracts.cli taxonomy --findings reports/current_impact.json --format markdown --output reports/current_impact_taxonomy.md
python3 -m telemetry_contracts.cli regenerate-artifacts --write --format markdown
```

## Figure/table/report artifacts

`reports/paper_tables.md` is regenerated by `regenerate-artifacts --write`. The command also refreshes current impact and claims evidence artifacts. Every generated report is deterministic over checked-in public fixtures; reconstructed datasets remain labeled as reconstructed.
