## Body (Show HN)

I built a tool on a simple thesis: **observability is a correctness property.**
If a failure is recorded but you can't tell which request it belonged to, that's
a *bug*, not a style preference — and it can be detected mechanically.

`telemetry-contracts` points at the telemetry you already have — JSON logs,
traces, metrics, logfmt, OTLP, whatever shape — and tells you which incident
questions you can't answer yet. There's nothing to adopt first: no contract to
write, no relabeling, no semantic conventions.

A few things that might interest this crowd:

- **Zero install / zero upload:** there's a browser playground that runs the
  *same* pure-stdlib engine client-side via Pyodide. Paste logs, get a
  diagnosability score and the specific gaps. Nothing leaves your machine.
- **It's deterministic:** SARIF output, the CI gate, the badge, the browser
  report, and a corpus study are all byte-reproducible (no wall-clock, no RNG).
- **It's evaluated like research:** a formal model with executable witnesses,
  baselines compared through one gold-set pipeline with a paired McNemar test,
  and a reproducible corpus study. On a small frozen corpus of repos authored
  without this tool in mind, *half* of the failure-bearing ones can't answer
  "which request failed?".
- **It drops into CI:** a GitHub Action posts a PR comment, uploads findings to
  the Security tab as SARIF, and fails the build under a score floor.

Pure Python stdlib + the git CLI. Would love feedback on the bug-class
definitions and on the corpus methodology.

## One-liner for comments

```
pip install "git+https://github.com/thehalleyyoung/telemetry-contract-semantics.git"

```

## Talking points / likely questions

- *"Isn't this just a linter?"* — The gap definitions are tied to a formal model
  and evaluated against ground truth with baselines, not hand-waved. The output
  is byte-deterministic so results are auditable.
- *"Does it need OpenTelemetry?"* — No. It auto-detects whatever you emit and
  reports semantic-convention coverage as one signal, not a prerequisite.
- *"What about my data privacy?"* — The playground runs entirely in your browser;
  the CLI runs locally. Nothing is uploaded.
