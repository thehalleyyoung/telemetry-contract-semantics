# Reproducing the measured results

Python 3.10+ with the standard library only, plus `git`. The results were
produced on 2026-10-06 with Python 3.14.7 on macOS. Every command runs from the
repository root.

## 1. Offline artifacts (no network)

```bash
python3 -m telemetry_contracts.cli reproduce --check   # regenerate + verify the 13-artifact SHA-256 manifest
python3 -m pytest -q                                   # full test suite
```

## 2. RQ1: gold-set accuracy

```bash
python3 -m telemetry_contracts.cli evaluate-gold --gold benchmarks/ground_truth/curated.jsonl --format json
# -> same content as reports/gold_evaluation.json
```

The gold set is regenerated by `python3 scripts/gen_gold.py`. It has a single
labeller and no second labels.

## 3. RQ2: baselines, including real LLMs

Offline replay of the recorded LLM responses:

```bash
python3 -m telemetry_contracts.cli compare-baselines --gold benchmarks/ground_truth/curated.jsonl --format json --output results/baseline_comparison.json
python3 -m telemetry_contracts.cli compare-baselines --gold benchmarks/ground_truth/curated.jsonl --output results/baseline_comparison.md
```

Re-recording the LLM responses needs network access and `OPENROUTER_API_KEY`.
It costs about US$0.08 and appends to `results/api_costs.jsonl`:

```bash
python3 scripts/run_llm_baseline.py --model anthropic/claude-haiku-4.5
python3 scripts/run_llm_baseline.py --model openai/gpt-4.1-mini
```

Raw logs: `results/llm_baseline/*.raw.jsonl`, one line per call with the
prompt, raw response, served model, provider, usage and cost. Replay caches:
`benchmarks/baselines/llm_*.json`. Decoding was temperature 0 with at most 200
tokens. Recorded on 2026-10-06 UTC; the provider for each call is in the raw log.

## 4. RQ3: corpus study (network, about 3.5 GB of checkouts)

```bash
python3 -m telemetry_contracts.cli corpus-download --manifest benchmarks/corpus/corpus.json --output results/rq3/download_report.json
python3 -m telemetry_contracts.cli corpus-run --manifest benchmarks/corpus/corpus.json \
  --repos-dir benchmarks/corpus/_repos --format markdown \
  --output results/rq3/study.md --dataset-output results/rq3/corpus_dataset.json
python3 scripts/rq3_extract_findings.py        # findings.jsonl + validation_sample.jsonl
python3 scripts/rq3_validation_summary.py      # validation_summary.json from validation_labels.csv
```

`results/rq3/validation_labels.csv` was written by a single LLM rater inspecting
each sampled event (see `results/rq3/README.md`). It is an input
to the summary script, not an output. One manifest subject
(`Alvoradozerouno/STEURER-Framework`) no longer exists upstream, so 58 of 59
subjects were analysed.

## Local semantic audit

Run `python3 audit/semantic_controls.py audit/results/semantic-after.json`,
`python3 audit/semantic_followup.py audit/results/semantic-followup-after.json`,
and `python3 audit/recount.py`. Frozen plans and before/after receipts are under
`audit/`. These commands make no API calls. Recount uses the production predictor
but independently implements confusion matrices and exact McNemar arithmetic.
The original corpus checkout directories are absent locally; recounting archived
JSON does not reproduce extraction or establish current corpus accuracy.

The 224 recorded API cost entries sum to $0.0774202. This is an artifact total,
not a verified billing statement. This audit spent $0 on OpenRouter and Modal.
